<h1>A Murder-Mystery Game made with PyGame</h1>
The game begins with a murder at the Royal Cresent Theatre. In this game, you play as a detective who must find clues and identify the murderer correctly.

You are provided with:
- Initial Investigation Report (with the details of deceased)
- Suspect lists
- Timeline

You are required to:
- Find the evidences on crime scene
- Interrogate the suspects individually for more clues
- Confirm the accusation

Game controls are specified in the game itself like:
- ↑ / ↓ / ← / → : Move
- Space or click: Interact
- Enter: Confirm
- Backspace: Return to the previous scene

Future Features:
- Add enemy behavior
- Add more levels
- Optimize UI
